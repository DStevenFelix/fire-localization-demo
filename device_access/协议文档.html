1. 帧格式总览

协议采用 TCP 二进制帧，大端字节序 (Big-Endian)。兼容双字节尾和单字节尾两种格式。

FF FE  |  Type  |  Rsv  |  Len  |  Data (Len 字节)  |  55 AA   ← 标准帧尾
FF FE  |  Type  |  Rsv  |  Len  |  Data (Len 字节)  |  AA   ← 兼容帧尾（单字节）
偏移字段长度说明
0Header 11B固定 0xFF
1Header 21B固定 0xFE
2Type1B设备类型（见各设备章节）
3Rsv1B消息类型（按设备类型语义不同）
4Len1BData 区字节长度 (0–255)
5DataLen载荷数据
5+LenTail1 或 2B55 AA 或 AA
帧尾自动检测：解析时先尝试匹配双字节尾 55 AA，失败则回退到单字节尾 AA。 光谱无人机 (Type=0x03) 使用单字节尾，其余设备使用双字节尾。

2. 轮式车 Type=0x01

帧结构

FF FE  |  01  |  01  |  20  |  X(8B) Y(8B) Z(8B) Vel(4B) Yaw(4B)  |  55 AA

Data 区结构 (32 字节，大端)

偏移字段类型字节说明
0Xfloat64 BE8X 坐标 (米)
8Yfloat64 BE8Y 坐标 (米)
16Zfloat64 BE8Z 坐标 (米)，地面车辆恒为 0
24Velocityfloat32 BE4线速度 (米/秒)
28Yawfloat32 BE4航向角 (度)

Python 构建示例

data = struct.pack('>dddff', x, y, 0.0, velocity, yaw) # 32 bytes frame = b'\xFF\xFE\x01\x01\x20' + data + b'\x55\xAA'

3. 无人机 Type=0x02

帧结构

FF FE  |  02  |  01  |  20  |  X(8B) Y(8B) Z(8B) Vel(4B) Yaw(4B)  |  55 AA

Data 区结构与轮式车完全相同（32 字节，大端）。区别仅在于：

  • Type 字段 = 0x02（与轮式车 0x01 不同）
  • Z 坐标有实际飞行高度值（轮式车恒为 0）
偏移字段类型字节说明
0Xfloat64 BE8X 坐标 (米)
8Yfloat64 BE8Y 坐标 (米)
16Zfloat64 BE8Z 坐标 (米)，飞行高度
24Velocityfloat32 BE4线速度 (米/秒)
28Yawfloat32 BE4航向角 (度)

Python 构建示例

data = struct.pack('>dddff', x, y, z, velocity, yaw) # 32 bytes frame = b'\xFF\xFE\x02\x01\x20' + data + b'\x55\xAA'

4. 光谱无人机 Type=0x03

帧结构

FF FE  |  03  |  01  |  07  |  ID(1B) X(3B) Y(3B)  |  AA
与标准定位帧的关键差异：Data 区仅 7 字节，单字节尾 AA（无 55 前导），坐标以厘米为单位传输。

Data 区结构 (7 字节，大端)

偏移字段类型字节说明
0RigidBodyIduint81刚体编号
1X (cm)int24 BE3X 坐标原始值 (厘米)，有符号
4Y (cm)int24 BE3Y 坐标原始值 (厘米)，有符号

解析端自动 ÷ 100 转为米。无 Z / Vel / Yaw 字段。

示例

# 01 FF FF D6 00 00 20 → 刚体 1, X=-42cm, Y=32cm

Python 构建示例

# int24 大端：X=-42 → FF FF D6，Y=32 → 00 00 20 data = bytes([rigid_body_id]) + b'\xFF\xFF\xD6' + b'\x00\x00\x20' frame = b'\xFF\xFE\x03\x01\x07' + data + b'\xAA'

5. 信号控制机 — 绿波方案 Type=0x04

帧结构

FF FE  |  04  |  01  |  Len  |  PlanName (UTF-8, Len 字节)  |  55 AA

Data 区结构

字段类型长度说明
PlanNameUTF-8 stringLen绿波方案名称

C# 端收到后自动执行：

  1. 查找 SeuGreenWaveConfigHelper.GetSeuGreenWaveByName(planName)
  2. 读取 4 台信号机的方案名称和相位差 (ms)
  3. 按信号机顺序各自异步：Task.Delay(相位差) → BusPhaseConfigHelper → PhasePaceHelper.CheckPaceListFlash → SignalAnalysisAgreement5.GetSendDataForPaces → UdpHelper.SendData(Ip, Port, ...)
  4. 弹出进度窗口显示 4 台信号机各自下发状态

Python 构建示例

data = "绿波方案1".encode("utf-8") frame = b'\xFF\xFE\x04\x01' + bytes([len(data)]) + data + b'\x55\xAA'

6. 火灾事故 Type=0x05

触发帧 (Rsv=0x01)

FF FE  |  05  |  01  |  Len  |  Name(UTF-8) + X(8B) + Y(8B) [+ W(4B) + H(4B)]  |  55 AA

取消帧 (Rsv=0x02)

FF FE  |  05  |  02  |  Len  |  Name (UTF-8, Len 字节)  |  55 AA

Data 区结构 — 触发帧

偏移字段类型字节说明
0NameUTF-8Len-coord事故名称
Len-coordXfloat64 BE8X 坐标 (米)
Len-coord+8Yfloat64 BE8Y 坐标 (米)
Len-coord+16Wfloat32 BE4显示宽度 (像素)，可选，缺省=64
Len-coord+20Hfloat32 BE4显示高度 (像素)，可选，缺省=64

Data 区结构 — 取消帧

字段类型长度说明
NameUTF-8Len要取消的事故名称（与触发时一致）

C# 端处理：触发 → 在地图上 SetOverlay("火灾", pixelX, pixelY, width, height) 显示 ic_fire 图标（默认 64×64）； 取消 → RemoveOverlay("FIRE_" + name) 移除。

Python 构建示例

# 触发火灾 name_bytes = "火灾点1".encode("utf-8") data = name_bytes + struct.pack('>dd', 3.0, 5.0) # 不带宽高（默认 64×64） frame = b'\xFF\xFE\x05\x01' + bytes([len(data)]) + data + b'\x55\xAA' # 取消火灾 data = "火灾点1".encode("utf-8") frame = b'\xFF\xFE\x05\x02' + bytes([len(data)]) + data + b'\x55\xAA'

8. 字节序转换参考

Python

# float64 大端读写 value = struct.unpack('>d', data[offset:offset+8])[0] data = struct.pack('>d', value) # float32 大端读写 value = struct.unpack('>f', data[offset:offset+4])[0] data = struct.pack('>f', value) # int24 有符号大端读写 b0, b1, b2 = data[offset], data[offset+1], data[offset+2] value = (b0 << 16) | (b1 << 8) | b2 if value & 0x800000: value |= -1 << 24 # 符号扩展

C#

// float64 大端读写 byte[] buf = new byte[8]; Array.Copy(data, offset, buf, 0, 8); if (BitConverter.IsLittleEndian) Array.Reverse(buf); double value = BitConverter.ToDouble(buf, 0); // float32 大端读写 byte[] buf = new byte[4]; Array.Copy(data, offset, buf, 0, 4); if (BitConverter.IsLittleEndian) Array.Reverse(buf); float value = BitConverter.ToSingle(buf, 0); // int24 有符号大端 int b0 = data[offset] & 0xFF, b1 = data[offset+1] & 0xFF, b2 = data[offset+2] & 0xFF; int value = (b0 << 16) | (b1 << 8) | b2; if ((value & 0x800000) != 0) value |= unchecked((int)0xFF000000);
