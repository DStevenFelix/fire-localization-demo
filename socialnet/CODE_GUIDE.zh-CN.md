# app 与 fire_locator 中文代码导读

当前为 CITY90x75 整城场景：415 个可检索对象、75 栋可发帖住宅、300 人、10 个居民群。社交网络与事件检测属于宿主，`fire_locator/` 为另一组的独立定位算法。八只原始储罐仍为真实火源和定位目标，扩展住宅仅参与居民生成、来源及地点参照。

## 运行链路

```text
main.lifespan → SimulationStore：打开、备份/迁移、恢复为暂停
开始/单步 → mutation（仿真锁）→ SimulationEngine.tick
  → 时间 +5 → 随机单火源与强度更新
  → 10 群并行，各群顺序生成日常、可选观察、回复
  → 私有 FireObservation → ExpressionPlan → ResidentAgent 正文
  → EventDiscovery 仅用公开正文/回复做七类本地召回与15分钟统计
  → 有新增火灾/燃气候选才调用 MonitorAgent + 最多32条公开回复上下文
  → 校验逐字引文 → MonitorReport → 关联原帖 outbox
  → 提交 SQLite 检查点与完整历史 → 唤醒定位 → 广播
LocalizationService → 后台顺序线程 → FireLocalizer
  → 每帖一个参照/方向 → 唯一名称/ID/别名优先 → 向量匹配
  → 15单位圆/45°扇形 → 八罐候选
  → 每候选独立累计1或0.34票、文本向量 → 全局Top3
  → 保存确认检查点 → WebSocket 增量 → 同坐标地图
```

居民/监测失败回滚整步；定位失败只停止定位队列，主仿真继续。数据库先保存再发布结果；模型已发请求的费用无法回滚。

| `app/expression.py` | 私有感知与历史记录、公开 `ExpressionPlan`、表达抽样、提示约束和正文轻量标注。`EvidenceClaim`、`ObservationUtterance`、`validate_observation` 是保留的结构化协议，当前居民生成不调用。 |
| `app/llm.py` | 提供商选择、Chat 工厂、角色温度/思考参数、统一超时与安全异常；OpenAI Key 优先，SDK自动重试关闭，不在此加载环境文件。 |
| `app/monitoring.py` | 公开消息筛选和模型研判，输出事件及逐字引用；宿主只送火灾/燃气候选+最多32条必要公开回复上下文；每事件至少引用一条新增，格式/引文错误最多四次尝试，请求异常直接失败。 |
| `app/localization.py` | 独立后台队列、原帖/报告去重、迟到重放、成功日志、时钟、会话及运行代际隔离。恢复与过期排名只信数据库确认的 Memory。 |
| `app/localization_provider.py` | 正式在线工厂，注入宿主 Chat 和专用 Embedding 配置；逐帖提取缓存、正文及 POI 名称缓存；请求仅一次尝试，记录安全耗时日志。 |
| `app/storage.py` | SQLite 单写者进程锁、事务、检查点、完整历史分页、轮次激活/删除、清理任务、格式4升级及候选/类别索引；旧档不回扫，从新消息启用发现统计。普通保存不隐式切档，删除当前记录同事务建新轮次。 |
| `app/city_migration.py` | 已知旧48人定义的纯数据迁移：核对旧指纹、平移坐标、补齐新增居民/社区与随机流，保留正文/证据/序号。旧定位票数不换算，不调用模型；由存储层备份后事务执行。 |
| `app/spatial.py` | 校验原图、整城数据和导入哈希，提供原始/扩展住宅及社区道路索引。原始住宅转换到CITY一次，扩展可发帖住宅直接使用。`localization_search_radius` 仅为全覆盖几何分析工具，正式半径采用新版15。 |
| `app/world.py` | 组合原始90项与扩展325项，创建统一实体/几何、300居民和地图元数据；原48人不改名，新居民唯一姓名并轮换人设。旧几何组件/管线辅助方法保留，当前实体构造不调用。 |
| `app/map_data.py` | 保留的旧 XLSX/几何 JSON 读取器，当前入口不引用。仍指向 map 下旧文件名，而旧数据现位于 map_old，不意味着旧路径当前可运行。 |

## fire_locator：独立定位模块

| 文件 | 实际功能与关键接口 |
| --- | --- |
| `fire_locator/__init__.py` | 独立算法包标识，不初始化模型。 |
| `fire_locator/config.py` | `Settings`：默认半径15、扇形45°、阈值0.7、30分钟窗口、批大小10；独立提供商参数可被宿主注入配置替代。 |
| `fire_locator/models.py` | 严格 `Post`、`Extraction`、`BatchExtraction` 契约；分钟时间统一上海时区，一个参照及一个方向，未知字段拒绝。 |
| `fire_locator/engine.py` | `FireLocalizer`：输入验证、摘要去重、pending持久化、批量处理、按候选加权证据、全局Top3和审计摘要。预测目标仍是八罐，所有输出CITY。 |
| `fire_locator/poi.py` | `PoiRepository` 合并415项，保留原生中心、校验底图和整城放置、来源can_post校验、方向/半径筛储罐。指纹取内容，不含本机绝对路径。 |
| `fire_locator/providers.py` | 批量地点提取、精确标签/歧义处理、语义向量检索；向量分批最多8条、缓存和POI名称预热、原子JSON。旧在线和显式离线实现保留，正式由宿主适配。 |
| `fire_locator/memory.py` | schema=3 的候选独立状态：pending、去重摘要、单候选样本/单位向量和/整数百分票；满30分钟冷却，新票建新窗，不再合并。恢复只接受同签名schema3。 |
| `fire_locator/math_utils.py` | 两组向量余弦矩阵、维度校验和零范数处理，供匹配器独立核算。 |
| `fire_locator/INTEGRATION.md` | 更新来源、保留算法、宿主注入/恢复适配、数据与存档边界，非运行入口。 |
| `fire_locator/UPSTREAM.json` | 导入源、日期和八个源文件哈希，供核对版本及本地兼容补丁，非运行配置。 |

## 定位统计及信息边界

- 真值驱动私有感知；监测只收到公开正文、来源与引用元数据；定位仅收到原帖ID、时间、正文、来源POI及紧急度，不包含真实火源ID、位置或强度。
- 住址是观察来源，不是确认起火地点。匹配无参照/歧义/低分时使用发帖POI是几何解析规则，不是模型失败时的离线回退。
- 0.34票仅用于正文无明确方向且无匹配地点的原帖。整数34/100累计防小数误差，一致性样本数仍按真实帖数。紧急度不参与当前排名公式。
- 每个候选独立累计向量，一致性是平均成对余弦，单帖约定1。得分为票数乘非负一致性，分数和颜色均不是校准火灾概率。
- 满30分钟无新票即退出排名；其他候选得票不会为它续期。旧存档的历史结果保留原60分钟标识，但不进入新版推理。
- 半径15不覆盖全部远端住宅到八罐；无候选不强行定位。合成测试不代表300人真实模型群聊命中率。
- 数据库是续跑权威；定位工作Memory/提取/向量JSON可能提前落盘，不能在恢复时覆盖数据库确认票数。历史分页不扩大模型记忆。
- 激活令牌、单调序号和运行代际区分同档的不同激活，防止旧HTTP、WebSocket和线程结果回写。

## 旧档与验证

已知旧版在格式1/2升3时先创建数据库备份，迁移活动和归档轮次及完整历史；失败事务回滚，重新打开不重复平移。原居民随机流、正文、证据和序号保留，新增居民随机流按稳定ID初始化。未知定义继续报不兼容。

旧合并Memory不能伪迁移为新版独立候选，保留旧预测供回看并暂停定位。旧档仍可载入群聊和报告，重置新轮次后使用新定位；schema3的模型配置不兼容继续严格拒绝混用。

核心回归在 `tests/test_localizer_core.py`，整城/迁移专项在 `tests/test_city_update.py`；其余测试覆盖社交生成、检测、定位编排、持久化与存档管理。浏览器检查使用独立模拟后端、临时数据库及测试模型，不访问正式存档或付费模型。`__pycache__/` 是自动字节码缓存，不逐个注释。

## 本地事件发现边界

`DiscoveryRecord` 保存原帖、多类别、规则及原文依据、转述/不确定/回复标记和版本；`DiscoveryState` 保存全城累计扫描/候选/送检/跳过次数、起点及处理进度、15分钟统计与最近50条。热度不是事实证明，作者数不是独立证人数，不合并跨社区事故，不输出概率。数据库保存完整候选，检查点仅保留有界窗口和当前待提交批次。

SQLite从格式3增表至4，不改定位Memory schema3、地图指纹或既有历史。重置/切档/删除及保存失败回滚覆盖发现数据，旧档从当前时间和消息序号之后开始统计。API `/api/discovery` 支持轮次校验、类别和社区筛选、排他消息序号分页。实现说明、规则限制、验证命令和按类别离线评测见 [EVENT_DISCOVERY.zh-CN.md](EVENT_DISCOVERY.zh-CN.md)。
